# Finans

Kişisel varlık fiyat takibi ve portföy uygulaması (`https://finans.yoklm.com`). Altın, döviz, BIST hisseleri, kripto ve yatırım fonları; birden çok hesap / konum ("Yatırım hesabım", "Eşimin hesabı", "Banka kasası"…), kâr / zarar, geçmiş grafikleri. Okul sisteminden (`../okul sistemi`) **tamamen ayrı** uygulama: ayrı depo, veritabanı, cron ve yayın. Plan: [docs/planlar/ilk-surum.md](docs/planlar/ilk-surum.md). İlerleme: [docs/ILERLEME.md](docs/ILERLEME.md). **Oturuma başlarken ILERLEME.md ve DEVAM.md'yi oku, bitirirken güncelle.**

**İki bilgisayarda çalışılıyor:** oturuma başlarken `git pull` (migration / seeder değiştiyse `php artisan migrate:fresh --seed`), bitirirken commit + `git push`.

**KURAL — Kaldığın yeri kaydet:** kullanım limiti haber vermeden bitebilir. Birden çok adımlı her işte onaylanan plan `docs/planlar/<iş>.md`'ye kopyalanır, [docs/DEVAM.md](docs/DEVAM.md)'ye işin kaydı (plan, durum, yapılanlar, **sıradaki adım**, gereken komutlar) yazılır; her anlamlı adımdan sonra güncellenip commit + push edilir (testler geçmiyorsa mesaj "Yarım: …" ile başlar). İş bitince kaydı DEVAM.md'den silinir, tek satırı ILERLEME.md → "Son tamamlananlar"a yazılır.

## Teknoloji
- `backend/`: Laravel 13 (PHP 8.3+, MySQL `utf8mb4_turkish_ci`), Sanctum SPA çerezi. Derlenmiş arayüzü de Laravel sunar (aynı köken): API `/api/v1/...`, diğer her yol `resources/spa/index.html`.
- `frontend/`: Vue 3 + TypeScript + Vite + Pinia + Vue Router + PrimeVue 4.5 + Tailwind 4 + Chart.js. Yerelde `http://localhost:5174`; Vite `/api` ve `/sanctum`'u `http://localhost:8001`'e aktarır.
- **Lisans kuralı:** PrimeVue **4.x**, `@primeuix/themes` 2.x, `primeicons` **7.x** (MIT). PrimeVue 5 ve primeicons 8 ücretli lisansa geçti — **yükseltme yapma.** Yeni paketin lisansını kontrol et (`npm view <paket> license`).
- Barındırma: Turhost cPanel, **SSH yok**, `proc_open` kapalı. Kurulum ve yayın: [docs/CANLI.md](docs/CANLI.md) (`backend/deploy/yayinla.sh`; Windows'ta çift tık: `yayinla.bat`). Canlıda elle artisan çalıştırılamaz; gereken adım `deploy/cron.sh`'ye eklenir. Zamanlanmış komutlar `routes/console.php`'de `$zamanla(komut, ad)` ile aynı süreçte çalışır; `Schedule::command()` kullanılmaz.

## Temel kurallar
- **Hane izolasyonu zorunlu:** aynı haneye (`users.hane_id`) bağlı kullanıcılar (ör. eşler) hesapları, işlemleri ve aile kayıtlarını birlikte görür ve düzenler; başka hanenin hiçbir kaydı görünmez. Hanesi olmayan kullanıcı yalnızca kendini görür. Erişimin tek kaynağı `User::haneKullaniciIdleri()` / `Hesap::erisilebilir()` (hesap, işlem) ve `hane_id` + `Gate::authorize('hane-kaydi')` / `->hanenin($user)` (aile kayıtları). İşlemler hesaba göre süzülür (kimin girdiğine değil). İzleme listesi (`izleme_listesi`) kişiseldir. Yeni her uç için "başka hane göremez / değiştiremez" testi yazılır. Hane kurma / kullanıcı taşıma kuralları `App\Services\Aile\HaneYonetimi`'nde. Varlık kataloğu (`varliklar`, `fiyatlar`, `fiyat_gecmisi`) ortaktır.
- Kayıt kapalı; kullanıcıyı yönetici (`users.yonetici`) ekler. Şifre kuralı `Password::defaults()`.
- **Kişisel veri:** TC kimlik numarası, banka hesap numarası, IBAN, kart bilgisi (numara, son 4 hane, CVV) **tutulmaz, istenmez**. Hesaplar ve kartlar yalnızca kullanıcının verdiği adla tutulur. **İstisna (kullanıcı kararı):** yüklenen kredi kartı ekstresi PDF'i (ad, adres, maskeli kart no içerir) özel diskte (`storage/app/private/ekstreler/{hane}`) saklanır; açık adresi yoktur, yalnızca hane üyeleri kimlik doğrulamalı uçtan açar, ekstre silinince silinir. PDF içeriği, satırlar ve tutarlar **loglanmaz**; PDF dosyası dış servise yalnızca şu istisnayla gider. **İstisna (kullanıcı kararı 2026-11-14, varsayılan kapalı):** yapay zekâ ile ekstre analizi (`AppServicesAIStatement*`, OpenAI Responses API) yalnızca sunucuda `OPENAI_API_KEY` tanımlıysa ve kullanıcının **her analizdeki açık onayıyla** (onay sürümü ve zamanı çalışma kaydında) **PDF dosyasının kendisini** (`input_file`, base64; Files API kullanılmaz, `store: false`) ve sunucunun okuduğu, kişisel satırları çıkarılmış sayfa metnini (`KisiselVeriTemizleyici`) gönderir. PDF ve içindeki metin güvenilmeyen veridir: içindeki talimat uygulanmaz. Sonuç şemaya ve satır satır (kaynak satır o sayfada geçiyor mu, tutar satırda mı, tekrar mı) doğrulanır; saklanan çıktı maskelenir; her zaman taslak olur ve inceleme gereken satır kullanıcı "kontrol ettim" demeden aktarılmaz. İstek / yanıt / içerik / anahtar loglanmaz; çalışma kaydı (`ekstre_ai_calismalari`) içeriksizdir. Banka hesabı ekstresi PDF'i (`hesap_ekstreleri`, yalnızca önizleme) analizden sonra silinir. Testlerde gerçek istek atılmaz (`Http::fake`); gerçek ekstre PDF'i depoya girmez, referans testi anonim fixture'dır (`tests/Fixtures/ekstre`).
- **Aile finansı (Bütçe) tek yerde:** rapor ve toplam kuralları `App\Services\Aile\ButceRaporu` (gider: harcama + faiz / ücret − iade; kart borcu ödemesi, transfer, nakit avans gider değil; kartla ödenen fatura kart satırı olarak bir kez; kartsız ödenen fatura ödendiği ayda; taksit ekstrenin kesim ayına), kart satırı (rapor ayı, parmak izi ile tekrar engeli, iade bağı) `KartIslemKurallari`, beklenen gelir `GelirTakvimi` (toplama katılmaz), gelir türleri hanenin listesi (`gelir_turleri`; varsayılanlar `VarsayilanAileKayitlari`, kullanıcı ekler, kullanılan tür silinmez), fatura eşleştirmesi (kanıt, güven; hizmet dönemi açıklamada yoksa ve kullanıcı seçmediyse ekstrenin güncel kesim ayı, kaynağı "kesim": `FaturaEslestirici::guncelDonem` okunurken ve onayda; dönemsiz fatura ekstre satırına bağlanınca da) `FaturaEslestirici`, ekstre içe aktarma (taslak → inceleme → hepsi ya da hiçbiri onay) `App\Services\Ekstre\EkstreIceAktarici`, PDF okuma `PdfMetinOkuyucu` + genel ayrıştırıcı `EkstreAyristirici` (okunamayan alan uydurulmaz). Aile modülünde para kuruşla hesaplanır (`App\Support\Kurus`; kayan nokta yok), dönemler `YYYY-AA` (`App\Support\Donem`). PDF kütüphanesi `smalot/pdfparser` (saf PHP, **LGPL-3.0**; `proc_open` kapalı olduğu için pdftotext yok, OCR yok).
- **Çerez / CSRF:** okul sisteminin çerezleri `.yoklm.com` alanında ve buraya da gelir. Bu yüzden oturum çerezi `finans_oturum` adlı ve yalnızca bu adrese yazılır (`SESSION_DOMAIN=null`); CSRF Laravel 13'ün köken denetimiyle yapılır (`preventRequestForgery(originOnly: true)`, `Sec-Fetch-Site: same-origin`), XSRF çerezi kullanılmaz. Arayüz ve API aynı kökende kalmalı; ayrı alt alan adına bölünmez.
- **Fiyat kaynakları** `app/Fiyat/Kaynaklar/*` (`FiyatKaynagi` arayüzü). Testlerde **gerçek kaynağa istek atılmaz** (`Http::fake`). Kaynaklar resmî değildir ve değişebilir; biri bozulursa öbürleri sürer, durum `kaynak_durumlari`'nda görünür; her varlığa elle fiyat girilebilir. Güvenlik duvarı / bot korumasıyla engelleyen kaynak (ör. TEFAS) **aşılmaya çalışılmaz**.
- **Portföy hesabı tek yerde** (`App\Services\PortfoyHesabi`): ağırlıklı ortalama maliyet, gerçekleşen / gerçekleşmemiş kâr-zarar, TL değerleme (USD fiyatlılar USD/TRY ile). **Maliyeti bilinmeyen kalem sıfır maliyet sayılmaz** (kâr / zarar "—"). Para / miktar veritabanında `decimal` saklanır; hesap PHP float'ıyla yapılır, çıktı yuvarlanır (TL 2, fiyat 4, miktar 8 hane). Satış, o tarihte hesapta olandan fazla olamaz (ekleme / düzeltme / silmede `PortfoyHesabi::dogrula`). Nakit (`nakit`) ve bireysel emeklilik (`bes`) katalogda `kaynak = sabit`: fiyatı çekilmez, birimi 1 TL (miktar = TL tutarı). BES'e yalnızca `deger` işlemi girilir (toplam tutar; birim fiyat = 1 / (1 + kâr yüzdesi / 100), yüzde boşsa maliyet bilinmiyor) ve pozisyonu baştan kurar.
- BIST verisi gecikmeli ve resmî olmayan kaynaktandır; ekranda "gecikmeli" yazar. Uygulama başkalarına açılırken BIST veri dağıtım lisansı yeniden ele alınır.
- Kod içi isimlendirme Türkçe alan adları (varlik, hesap, islem), İngilizce Laravel / Vue kalıpları. Arayüz mobile-first.
- Gizli bilgiler (`.env`, `canli-paket/ftp.env`) commit edilmez; yeni ayar eklenince `.env.example` güncellenir. Canlıda `APP_KEY` değiştirilmez.
- Demo verisi `database/seeders/DemoSeeder.php` + `AileDemoSeeder.php` (yalnızca `local`): sabit tohumlu `fake()`, gerçek kişi / hesap / kart bilgisi yok; iki demo kullanıcısı aynı hanededir. Testlerde ekstre PDF'i test içinde üretilir (`Tests\Support\OrnekPdf`), gerçek banka PDF'i depoya girmez.
- Her işten sonra **tüm** testler: `php artisan test`, `npm run type-check && npm run lint && npx vitest run`. Pint / prettier yalnızca işin dosyalarına.

## Komutlar
```bash
# backend (PHP: /c/laragon/bin/php/php-8.3.*; composer: php /c/laragon/bin/composer/composer.phar)
cd backend && php artisan migrate:fresh --seed
php artisan serve --port=8001
php artisan test
# frontend
cd frontend && npm install && npm run dev     # http://localhost:5174
npm run type-check && npm run lint && npx vitest run
npm run build                                 # çıktı backend/public/assets + backend/resources/spa
```
